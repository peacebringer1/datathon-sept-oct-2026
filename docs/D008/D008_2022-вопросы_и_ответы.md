# Датасет D008, 2021. Домохозяйство, контрольная карточка состава домашнего хозяйства.

Полностью аналогичен D008-2021.

## Идентификационные данные.

- Te (Character, 2) - код территории;
- K (Character, 1) - код местожительства;
- Nomer (Character, 10) - код домохозяйства;
- Kol_chl (Character, 2) - количество членов домохозяйства;
- Nomp (Character, 2) - порядковый номер;
- Rodstvo (Character, 2) - родство;
- God_rojd (Character, 4) - год рождения;
- Mes_rojd (Character, 2) - месяц рождения;
- Pol (Character, 1) - пол;
- Rost (Numeric, 3) - рост;
- Sem_pol (Character, 2) - семейное положение;
- Urov (Character, 1) - уровень образования;
- Vr_ots (Character, 2) - код временного отсутствия;
- Izm_sost (Numeric, 1) - переключатель изменения состава;
- Pr_iza (Character, 2) - изменение состава в апреле;
- Pr_izi (Character, 2) - изменение состава в июле;
- Pr_izo (Character, 2) - изменение состава в октябре;
- Pr_izya (Character, 2) - изменение состава в январе;
- God (Character, 4) - год;
- Status (Character, 1) - статус основной деятельности на 1 января отчетного года;
- Statusf (Character, 2) - заполняется для работающих по найму у физических лиц (код 11);
- Status1_ Status4 (Character, 1) - изменение статуса основной деятельности поквартально;
- Statusf2_ Statusf4 (Character, 2) - заполняется поквартально для работающих по найму у физических лиц (код 11).
