# Датасет D002, 2021. Домохозяйство.

## Идентификационные данные.

- GODO - год;
- Te - код территории по КАТО;
- K - код типа населенного пункта (1 - город, 2 - село);
- Nomp - номер лица;
- Pol - пол лица (1 - непонятно, 2 - непонятно). В документации не описано это;
- Voz - возраст лица;
